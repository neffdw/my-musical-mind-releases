# My Musical Mind — release files

Installers for **My Musical Mind**, a desktop app for guitarists and songwriters
(Windows and Mac). The app's *File → Check for Updates…* reads `latest.json`
here to find out whether a newer version exists, and its Download button
fetches the installer from the newest release:

- Windows: `releases/latest/download/My-Musical-Mind-Setup.exe`
- Mac: `releases/latest/download/My-Musical-Mind.dmg`

Every release uploads its installers under exactly those two names.

This repository holds finished release files only — no source code.
